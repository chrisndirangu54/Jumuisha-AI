# Delivery matrix (do not misrepresent prototype coverage)

| Feature | State | Completion requirement |
| --- | --- | --- |
| Public government services directory | Implemented starter | Agency content audit and versioned source snapshots |
| English/Kiswahili deterministic discovery | Implemented starter | Field-tested language and dialect coverage |
| Voice output | Flutter TTS adapter | Flutter platform builds and device tests |
| Speech-to-text | Not integrated | Consent-aware permissions, Kenyan language evaluation, on-device/offline fallback |
| Braille | OS accessibility semantics path | Test BRLTTY / iOS / Android with actual refreshable displays |
| KSL | Manifest + fallback | Licensed human-reviewed compressed MP4 and 2D sprite media, interpreter relationships |
| KSL recognition / generative signing | Not implemented | Co-design, representative data, signed-off evaluation |
| Easy Read / adjustable interface | Basic UI | Expert usability testing and full translated content |
| Switch control / AAC | Platform semantics + symbol metadata | Hardware and communication board testing |
| Offline data | Cache for public catalogue | Encrypted authenticated draft sync and conflict resolution |
| Identity and delegated access | Not implemented | OIDC, server-side scopes, revocation, government data agreement |
| KRA, eCitizen, SHA, NTSA and other agencies | Catalogue only | Official specifications, authorization, sandbox, credentials and test certification |
| Human-assistance plans | Guidance only | Authorized service provider network and booking integrations |
| USSD/SMS/IVR | Not implemented | Telco accounts, short codes, secure session service and carrier QA |
| Transactional payments | Not implemented | Approved payment processor, lawful recipient, reconciliation |
| Performance/analytics | Test-ready API | Consented privacy-preserving metrics and accessibility outcomes |
| Accessible kiosk and locator | Not implemented | Hardware procurement and verified facility data |

**Non-negotiable:** no production citizen data, automatic official filing, invented benefits determinations, or unreviewed signing output until appropriate external approvals and evidence exist.

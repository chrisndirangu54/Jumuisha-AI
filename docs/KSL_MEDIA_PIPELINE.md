# Lightweight KSL delivery
Production default: human-validated compressed MP4 (H.264, low resolution and adaptive bitrate). 2D WebP sprites are an alternative for very short approved phrases. Freehand autogenerated poses, animated avatars and arbitrary video synthesis must not be labelled Kenyan Sign Language without native KSL review.

A reviewer must approve each exact phrase and provide consent/licensing, captions, asset checksums, version, and a fallback text transcript. Serve only HTTPS URLs from an allowlisted media host, confirm checksum when downloaded, and use app caching only after licensing and device privacy evaluation. The current KslPlayer is a UI building block and **does not itself verify license/checksum/host**; production ingestion must enforce these.

The initial manifest intentionally has no recordings. Users should always have text and a qualified human interpreter alternative.
